# Image server
# Описание


Image Server  — веб-приложение для загрузки, хранения и управления изображениями.

Проект построен на Flask и PostgreSQL, поддерживает хранение метаданных изображений, пагинацию, удаление файлов и резервное копирование базы данных. Для контейнеризации используется Docker Compose.

### Возможности

* загрузка изображений (JPG, PNG, GIF);
* хранение файлов на диске;
* хранение метаданных в PostgreSQL;
* просмотр списка изображений;
* пагинация списка изображений;
* удаление изображений;
* логирование операций;
* резервное копирование базы данных.

## Загрузка изображений

Маршрут:

```http
POST /upload
```

Поддерживаемые форматы:

* JPG
* PNG
* GIF

Максимальный размер файла:

```text
5 MB
```

После загрузки:

1. файл сохраняется в директорию `images/`;
2. метаданные записываются в PostgreSQL.

---

## 🗂 Метаданные изображений

Для каждого изображения сохраняются:

| Поле          | Описание                  |
| ------------- | ------------------------- |
| id            | идентификатор             |
| filename      | сгенерированное имя файла |
| original_name | исходное имя              |
| size          | размер файла              |
| upload_time   | время загрузки            |
| file_type     | тип файла                 |

---

##  Список изображений

Маршрут:

```http
GET /images-list
```

Отображается:

* имя файла;
* оригинальное имя;
* размер;
* дата загрузки;
* тип файла;
* ссылка на изображение.

Сортировка:

```sql
ORDER BY upload_time DESC
```

---

## Пагинация

Пример запроса:

```sql
SELECT *
FROM images
ORDER BY upload_time DESC
LIMIT 10 OFFSET <offset>;
```

Особенности:

* 10 изображений на страницу;
* сортировка по дате загрузки;
* новые изображения отображаются первыми.

Примеры:

```text
/images-list?page=1
/images-list?page=2
```

---

##  Удаление изображений

Удаление записи из базы данных:

```http
POST /delete/db/<id>
```

Удаление файла:

```http
POST /delete/<image_id>
```

При удалении:

* удаляется запись из PostgreSQL;
* удаляется файл из файловой системы.

---

##  Резервное копирование

Создание резервной копии:

```bash
docker exec -t postgres_container \
pg_dump -U postgres images_db \
> backups/backup_YYYY-MM-DD_HHMMSS.sql
```

Восстановление:

```bash
docker exec -i postgres_container \
psql -U postgres images_db \
< backup.sql
```
